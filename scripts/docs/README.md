# เอกสารส่งมอบและคู่มือ (.docx)

`make-handover-docs.py` สร้างไฟล์สองฉบับใน `docs/`:

- `เอกสารส่งมอบระบบ HygienePro.docx` — สำหรับฝ่าย IT และผู้รับมอบระบบ
- `คู่มือการใช้งาน HygienePro.docx` — สำหรับผู้ใช้งาน QA หัวหน้างาน และผู้จัดการ

## วิธีสร้างใหม่

ต้องมี `python-docx` (`pip install python-docx`) แล้วรันจากรากโปรเจกต์:

```
python scripts\docs\make-handover-docs.py
```

ไฟล์เดิมจะถูกเขียนทับ **อย่าแก้ไขไฟล์ .docx โดยตรง** แก้ที่สคริปต์นี้แล้วสร้างใหม่

**ทำไม:** เอกสารส่งมอบมีตัวเลขและเส้นทางไฟล์ที่ต้องตรงกับระบบจริง เช่น ตารางงานอัตโนมัติ
และรายการตรวจก่อน Go-live ถ้าแก้ในไฟล์ Word ความจริงจะอยู่สองที่ และสำเนาที่ส่งมอบไปแล้ว
จะไม่มีใครรู้ว่าเวอร์ชันไหนถูก การมีต้นฉบับเป็นสคริปต์ทำให้เอกสารถูก review พร้อมโค้ด
ในรอบเดียวกัน

## เมื่อแก้อะไรที่กระทบเอกสาร

ส่วนที่เก่าเร็วที่สุดคือ:

- ตารางงานอัตโนมัติ (ต้องตรงกับ `routes/console.php`)
- สภาพแวดล้อมของระบบ (path, พอร์ต, เวอร์ชัน PHP/MySQL)
- รายการตรวจก่อน Go-live และหัวข้อ "ข้อจำกัดและงานที่ยังไม่เสร็จ"
- หัวข้อ "การอ่านข้อความแจ้งเตือนตอนเช้า" ในคู่มือ (ต้องตรงกับ `OverdueCARLineNotification`)
